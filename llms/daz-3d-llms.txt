# DAZ 3D

> Daz 3D is a Salt Lake City based 3D content and software company best known for Daz
> Studio, a free figure posing, morphing and rendering application, and for the Genesis
> line of morphable 3D human figures. Its developer surface is an APPLICATION SDK, not a
> web API: a free C++ plug-in SDK, the DAZ Script ECMAScript scripting API, and
> open-source Daz-to-DCC bridge plug-ins on GitHub.

## What an agent can and cannot do here

- There is NO public REST, GraphQL, gRPC, webhook or event API. Contract discovery probed
  www.daz3d.com, docs.daz3d.com and api.daz3d.com for /openapi.json, /openapi.yaml,
  /swagger.json, /v1/openapi.json, /api-docs, /graphql, the Magento REST and Swagger
  paths (/rest/V1/*, /rest/all/schema?services=all, /swagger, /soap?wsdl_list=1) and the
  full /.well-known/ set. Every one returned 404, or 302 to the marketing site.
- api.daz3d.com resolves but is NOT an API host — every path 302s to https://www.daz3d.com/.
  Do not treat it as a base URL.
- The programmable surface is LOCAL: DAZ Script runs inside a locally installed Daz Studio.
  Automating Daz means scripting the application, not calling a service.
- No authentication model, no OAuth scopes, no rate limits, no idempotency semantics, no
  error catalog — none of these exist because there is no HTTP API.

## The API surface, precisely

- DAZ Script — an ECMAScript/JavaScript scripting API built on Qt Script, with an Object
  Index, Intrinsic Types (Modules), Samples, an Action Index and a porting guide from
  QSA/DAZ Script 1. In-process, application-scoped.
- DAZ Studio 4.5+ SDK — C++ headers and libraries, SDK documentation and sample plug-ins,
  Windows and macOS. Free ($0.00, store SKU 14876) but requires a Daz account and Daz
  Studio 4.x Pro. https://www.daz3d.com/daz-studio-4-5-sdk
- DSON — Daz's own JSON-based scene/asset file format. Human-readable spec only; no JSON
  Schema is published, so a parser must be written from the prose.

## Agent / MCP

Daz 3D ships no first-party MCP server. Third-party community MCP servers exist and drive
a locally running Daz Studio over the DazScriptServer plug-in — see
mcp/daz-3d-mcp.yml in this profile. They are not Daz products.
